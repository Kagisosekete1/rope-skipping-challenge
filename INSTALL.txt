Rope Skipping Challenge v2

1. Install Node.js 20.19+ or 22.12+.
2. In this project folder run: npm ci
3. Run: npm run dev
4. Open the address printed by Vite.

For web hosting: npm run build, then upload dist/ to an HTTPS static host.
For phone installation: open the HTTPS game URL in Chrome or Safari and use
Install app / Add to Home Screen. Settings also contains an installation button.
The production build caches the game locally after its first successful load.

Progress stays on the device/browser. GitHub stores source; uploading source
alone does not create a playable hosted URL.
