ROPE SKIPPING CHALLENGE - INSTALL ON YOUR PHONE
(an installable app needs a web address; these steps take about 2 minutes and are free)

1. Unzip this folder on a computer (or phone).
2. Put the folder online, using ONE of these:
   - Netlify Drop: go to app.netlify.com/drop and drag the whole folder in. You get an https address immediately.
   - Cloudflare Pages: Workers and Pages > Create > Pages > Upload assets, upload the folder.
   - GitHub Pages: create a repository, upload these files, then Settings > Pages > deploy from the main branch.
3. Open the https address on your phone.
4. Install:
   - Android (Chrome): tap Settings in the game then "Install app on this phone", or browser menu > Install app.
   - iPhone (Safari): tap Share > Add to Home Screen.
5. Open it from the new home-screen icon. After the first load it also works offline.

Notes: Online play with a friend only works in the Claude version. Progress is saved per address.
When you update the game, upload the new files; the app refreshes the next time it opens online.
